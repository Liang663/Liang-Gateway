# Liang Gateway 前端演示

直接用浏览器打开 `index.html`，无需安装依赖或启动 Java 后端。页面为单文件 HTML，CSS、JavaScript、图表和图标全部内置，不需要网络。

## 演示范围

- 概览：模拟指标、24 小时 / 7 天趋势、模型分布、令牌额度和最近调用。
- 模型管理：搜索、添加演示模型、切换启用状态。
- 令牌与额度：创建演示条目、切换启用状态、确认后重置模拟用量。
- MCP 工具：服务和工具目录、OpenAPI JSON 示例导入。
- 调用日志：关键词和状态筛选、详情、CSV 导出。
- 调试台：本地模拟 SSE 打字效果和 MCP JSON 结果；支持停止输出。

所有状态仅存于页面内存，刷新恢复。所有指标、价格、模型和服务配置均为样例，不能作为真实性能或计费依据。OpenAPI 导入仅演示路径和名称识别，不替代后端解析器。没有接入鉴权、MySQL、Redis、模型或业务上游，请勿输入真实凭据与敏感数据。

## 后续接入方向

模型和凭据对应 `/admin/llm/models`、`/admin/llm/apikeys`；用户令牌对应 `/admin/users/{userCode}/tokens`；MCP 对应 `/admin/mcp/servers` 和工具接口；调用方用量对应 `/v1/usage/*`。首页聚合指标及全局日志列表需要进一步确认或补充后端统计接口，演示中的视图不代表这些接口已经具备。

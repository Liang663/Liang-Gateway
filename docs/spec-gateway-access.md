## 1. 背景与目标

- 背景：Security 只能回答「能不能进网关」。套餐窗口、够不够用、用了多少、明细是什么，是调用方业务。必须由本领域提供 API，供 `orchestration` 显式调用，并给用户与管理展示。
- 目标：识别调用方、拒绝非法凭证、按访问令牌做请求防刷与编码套餐式 Token 限额，记录用量，提供当前窗口与统计查询。

## 2. 范围

### 纳入范围

- 数据面凭证：`Authorization: Bearer`、`api-key` 头、query `api_key`。
- 管理凭证：`X-Admin-Token`。
- 用户、访问令牌、用量明细；令牌上的限额配置。
- 令牌绑定大模型 Key 后打开当前五小时窗口与当前七天窗口。
- 查询/检查/记账前的懒刷新；管理面手动重置。
- 额度检查、实际 Token 计数、额度条、按时/日/周/月/总量统计、用量明细。
- QPM 防刷。用户与令牌管理 HTTP。

### 不纳入范围

- 反向代理、过滤器链、Health（core）。
- Chat / MCP 协议、从响应读 `usage`、大模型 Key 的 CRUD（ai）。
- 数据面 Chat/MCP 入口（orchestration）。
- 字符粗估、预扣、中途掐流、预付费剩余池、上下文 BPE。
- 把额度做成 core 的 Filter。

### 依赖领域

- 无。

### 禁止依赖领域

- `core`、`ai`、`orchestration`。

## 3. 公开能力

- **进门鉴权：** 无/无效凭证不得进入数据面；无/无效管理令牌不得进入管理面。不负责额度。
- **额度检查与记账：** 编排在转发前询问能否继续，转发后按 prompt/completion 记账。
- **套餐窗口：** 每把令牌只有当前五小时窗口和当前七天窗口；可查已用、限额、起止。到期懒刷新；管理可手动重置。
- **用量账本：** 可查每一笔明细，以及时、日、周、月、总量汇总。
- **调用方管理：** 维护用户与访问令牌、启用停用、调整限额。

不公开：DeepSeek、MCP JSON-RPC、拷流、大模型 secret。读 `usage`、出站 Key 主数据归 ai。

## 4. 需求重点

- 模仿编码套餐：时钟和记账分开。窗口打开后墙钟走到结束即到期；记账只给当前窗口已用加数。没调用时钟也走。
- 每层只存一扇打开的窗口，不预切未来所有段。
- 任何需要查询或使用额度的路径（检查、记账、看额度条）都必须先判断要不要刷新。
- 进门失败 401；超额 429；检查阶段 Redis 不可用 503。计不了量不能放行。
- 不预估、不预扣。无 `usage` 不记 Token。
- 三层同时生效：QPM、当前五小时、当前七天。限额挂在令牌上。
- 窗口活状态在 Redis；限额与明细在 MySQL。第一版无缓存。

## 5. 设计重点

- 额度是本领域 API，由 orchestration 调用，不是 `GatewayFilter`。
- 创建令牌（必绑 `apikey_code`）时打开两扇窗口：`start=now`，`used=0`。未打 Chat 也能展示额度条。
- **到期刷新：** `n = floor((now - start) / 时长)`；若 `n >= 1`，则 `start = start + n * 时长`，`used = 0`。新窗口接在上一扇结束点上。例：7–12 点用完，14 点再来，五小时是 12–17 点，不是 14–19 点。五小时与七天各自判断。无定时任务。
- **手动重置：** 只有这条把 `start=now`、`used=0`。
- 刷新与加减必须原子完成。禁止每次记账把窗口往后延（那是滑动窗口）。
- QPM 是自然分钟请求次数，与套餐窗口无关。
- 展示看当前窗口；统计从明细按日历（`Asia/Shanghai`）聚合，和套餐切段不是一把尺。
- 鉴权成功后上下文带 `user.code`、`token.code`、`apikey_code`。本领域不读大模型 secret。
- 表结构以 SQL 为准。JPA 不得在事件循环上跑。

## 6. 领域规约

- 不得 import `core` / `ai` / `orchestration`。
- 不得把入站密钥或大模型 secret 写入可提交配置或日志明文。
- 禁用用户、禁用或过期令牌视为无效凭证（401）。
- Redis 与明细不得用表 `id` 或 `access_token` 当主体，用 `user_access_token.code`。
- `checkQuota` 在 Redis 失败时必须拒绝，禁止放行。
- 本领域不解析模型响应体，不 `collectList` / `block`。
- 结构验证：access 无出边依赖。

## 7. 验收标准

- 无 Key / 错 Key / 禁用或过期 → 401。
- QPM、当前五小时、当前七天任一超额 → 429。
- 令牌一创建即可查出两档额度条（用量可为 0）。
- 窗口未到期时持续调用不延长本扇；到期后再访问，已用归零，`start` 等于上一扇结束点。
- 管理重置后 `start=now`、已用归零。
- 记账后明细可查；时/日/周/月/总量与明细合计一致。
- Redis 在检查阶段不可用 → 503。
- 计数测试打真实 Redis；禁止内存 Map 冒充。

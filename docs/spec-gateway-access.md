## 1. 背景与目标

- 背景：Security 只能回答「能不能进网关」。这把钥匙能用哪些模型、金额窗口够不够、用了多少 Token 和钱，是调用方业务。由本领域提供 API，供 `orchestration` 在调 ai **之前 / 之后**显式调用。
- 目标：识别调用方、拒绝非法凭证、按令牌做模型授权与金额窗口限额，记录 Token 与金额，提供窗口与按模型分组的用量。

## 2. 范围

### 纳入范围

- 数据面凭证与管理凭证。
- 用户、访问令牌、令牌–模型名授权、金额窗口限额、用量明细。
- 五小时 / 七天 **金额** 窗口（懒刷新、手动重置）、QPM；可不限额。
- 记账：Token 与金额；日历时/日/周/月/总量按模型名分组，扫明细。
- 查询这把钥匙授权的模型名列表（只给名字，不含单价）。

### 不纳入范围

- 模型目录、官方单价、出站 Key、组上游请求、读 `usage`（ai）。
- 反代（core）。数据面 Chat/MCP HTTP（orchestration）。
- 出站 TTFT、故障率、出站 Key 日志（ai）。
- 字符粗估、预扣、中途掐流。本领域不 import ai 去对单价。

### 依赖领域

- 无。

### 禁止依赖领域

- `core`、`ai`、`orchestration`。

## 3. 公开能力

- **进门鉴权：** 无/无效凭证不得进数据面；无/无效管理令牌不得进管理面。
- **模型授权：** 编排可问某把令牌能否使用请求里的 `model`；可列出已授权模型名。
- **金额额度：** 编排转发前询问金额窗口是否还能用；转发后按编排传入的金额累加。
- **用量账本：** 记 Token 与金额；可查明细与按模型名分组的汇总。
- **调用方管理：** 用户与令牌、授权模型、金额窗口限额。

不公开：模型单价、供应商协议、secret。

## 4. 需求重点

- 套餐窗口 **只限金额**，不再限 Token。Token 仍记在明细里。
- 金额最小单位是 **分**。限额、Redis `used`、明细金额都是整数分。
- 金额限额在独立限额行上，不在令牌列上。`0` 不限额；`1` 五小时；`2` 七天（时长 7 天）。`1` 与 `2` 可同时在，不要与 `0` 并存。
- 判超限只读 Redis。本笔金额一次加上去，不是按分循环加。写额度时把 Redis 新 `used` 回写限额行，相当于持久化，不是第二套算法。窗口到期清零同样回写。
- 授权存 **模型名字符串**，不对 ai 表建外键。
- 时钟与记账分开；查询/检查/记账前懒刷新；到期 `start += n * 时长`；只有手动重置 `start=now`。
- 进门 401；未授权模型 403；超额 429；检查阶段 Redis 不可用 503。不预估、不预扣。
- QPM 仍在令牌上，每分钟请求次数，与金额窗口同时生效。
- 调用方统计扫用量明细。出站健康度不在本领域。

## 5. 设计重点

- 编排顺序：access 授权 + 金额检查 → ai 调用 → access 记账。access 不调 ai。
- 创建令牌：不限额写一行类型 `0`；否则写五小时和/或七天行，并打开对应 Redis 窗。
- 记账入参含 prompt、completion、金额（分）、模型名。金额由 ai 算好经编排传入。Chat 路径必须先拿到上游 usage 再记；不是「没 usage 就记 0」。失败出站不写用量明细。
- MCP 数据面不调本领域 `checkQuota` / `recordUsage`。QPM 与金额窗只约束模型调用。
- 鉴权上下文：`user.code`、`token.code`。出站 Key 不再挂在令牌上。
- 表结构以 SQL 为准。

## 6. 领域规约

- 不得 import `core` / `ai` / `orchestration`。
- 不得把入站密钥或大模型 secret 写入可提交配置或日志明文。
- 禁用/过期令牌视为无效凭证。未授权模型由本领域拒绝，不交给 ai。
- Redis 与明细主体用 `user_access_token.code`。
- `checkQuota` 遇 Redis 失败必须拒绝。
- 结构验证：access 无出边。

## 7. 验收标准

- 无 Key / 错 Key / 禁用或过期 → 401。
- 未授权模型 → 403 `forbidden`。QPM 或五小时/七天金额超额 → 429。
- 额度条单位是分；未调用时已用为 0。不限额令牌不做金额超额 429。
- 到期刷新接到上一扇结束点；手动重置 `start=now`。
- 明细可按模型名汇总 Token 与金额。
- Redis 检查失败 → 503。计数测试打真实 Redis。
